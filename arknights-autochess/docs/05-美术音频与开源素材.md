# 05 · 美术音频与开源素材（「有没有开源角色？」）

先回答原问题：**《明日方舟》的官方角色立绘/小人/模型没有「开源」许可，不能合法再分发。**
社区里能找到的是玩家从客户端提取的资源镜像——可以个人研究、做非商业同人，但不是开源授权，
公开分发/商用有版权风险。要公开发布，请用自制美术、CC0/OFL 素材，或买授权。

## 1. 结论速览

| 需求 | 能直接用？ | 建议 |
|---|---|---|
| 官方角色立绘、Spine 小人、头像 | ❌ 无开源许可（版权归鹰角） | 个人本机研究可以放 `public/assets-local/`（不提交）；公开发布不行 |
| 官方 UI 图标/界面图/音乐/音效 | ❌ 同上 | 自制或用 CC0 替代 |
| 官方数据表（干员数值/技能表） | ❌ 无开源许可（游戏数据同样受版权保护） | 可以本地参考结构与量级，不直接照搬数值；公开发布不要带数据表 |
| 社区「资源镜像」仓库 | ⚠️ 是提取物，非授权 | 只用于个人研究；不提交、不再分发 |
| 解包/提取工具 | ✅ 工具代码有开源许可 | 可以用，但提取出来的资源仍受版权约束 |
| CC0/买断/自制角色 | ✅ | **公开发布走这条路**，见第 4 节 |
| 字体 | ⚠️ 分字体 | 用 OFL 字体（思源黑体/Noto/霞鹜文楷）；官方字体（Bender/Novecento）条款需自行确认 |
| 音频 | ⚠️ 分来源 | Freesound 逐项看 CC0/CC-BY；或自制/买授权 |

> 参考：同类非官方复刻项目 Stronghold-Protocol 在自己的 NOTICE 里明确写明——代码 GPL-3.0，
> 但《明日方舟》的素材/数据**不属于** GPL，只能学习与个人非商业使用，禁止售卖、付费开服、广告、
> 打赏等任何盈利形式，权利人可要求删除。这就是「同人项目的现实边界」。

## 3. 为什么不能直接「用官方素材做一个能公开玩的版本」

- 角色、立绘、模型、音乐、数据是受版权保护的作品，不是「从客户端里拿到的文件」就归你；
- 游戏公司对同人通常容忍非商业、非授权的个人创作，但**容忍 ≠ 授权**，随时可能要求下架；
- 一旦涉及收费、广告、付费开服、赞助，性质就变了（这也是同类项目把「非商业」写进 NOTICE 的原因）；
- 公开仓库里提交素材，等于让所有 fork 都带上了侵权内容，风险会被放大。

所以本项目的原则：**仓库只放代码、自写的规则和占位图；版权素材永远停在本地。**

## 4. 可以安全使用的素材方向（推荐）

| 类型 | 来源 | 许可 | 备注 |
|---|---|---|---|
| 程序化占位 | 本项目的 PixiJS `Graphics` | 自有 | 当前 M0 的做法：格子/标记/单位全是代码画的 |
| 通用 2D 素材 | [Kenney](https://kenney.nl/assets) | CC0 | 角色/界面/音效都有，风格偏卡通 |
| 通用 2D 素材 | [OpenGameArt](https://opengameart.org/) | 逐项（CC0/CC-BY/GPL） | 每份资源单独看许可，CC-BY 要署名 |
| 免费/付费素材 | itch.io 素材包 | 逐项 | 很多「可商用」包，购买时看清条款 |
| 图标 | [Lucide](https://lucide.dev/)（ISC）、[Iconoir](https://iconoir.com/)（MIT）、[Tabler](https://tabler.io/icons)（MIT） | 宽松 | 方舟风 UI 图标可以先用它们 |
| 中文字体 | 思源黑体 / Noto Sans SC、[霞鹜文楷](https://github.com/lxgw/LxgwWenKai) | SIL OFL 1.1 | 可商用、可再分发（保留 OFL） |
| 西文/数字 | Rajdhani、Oxanium 等 | SIL OFL 1.1 | 科幻感数字字体 |
| 音效/音乐 | [Freesound](https://freesound.org/)、[Pixabay](https://pixabay.com/) | 逐项（CC0/CC-BY/自带许可） | 逐项记录作者与许可 |
| 自制/AI 生成 | 自己画或生成 | 自有（注意工具条款） | AI 生成请记录来源与工具条款，避免生成知名角色 |
| 委托画师 | 约稿 | 买断/授权合同 | 公开发布最稳妥的原创路线 |

> 如果只是「本机自己玩、不发布」，用官方素材的风险主要是个人道德/合规判断，但**不要提交到本仓库**。

## 5. 本项目的素材策略（三层）

| 层 | 位置 | 内容 | 是否进 Git |
|---|---|---|---|
| 仓库层 | `public/assets/`、`assets-src/` | 自制占位、CC0/OFL 资源、导出件/源文件 | ✅ 只放可公开分发的 |
| 本地层 | `public/assets-local/`、`content-local/` | 个人研究用官方素材/数据 | ❌ `.gitignore` 已忽略 |
| 发布层 | 构建产物 | 发布前跑许可清单，更新 `NOTICE.md` 与第三方声明 | — |

技术上的安排：

- `src/render/` 预留 **asset registry**（M1）：资源按 id 映射到 URL，逻辑层只认 id，换素材不动代码；
- 占位阶段全部用 `Graphics` 程序化绘制，所以**没有素材也能跑**；
- 立绘/小人建议：立绘 1024×1024 WebP、头像 256×256、小人用 sprite sheet 或 Spine；
- **Spine 注意**：`pixi-spine` 含 Spine Runtimes，受 Spine Runtimes License 约束（再分发要带许可声明，
  某些用法还要求使用者自备 Spine Editor 授权），本项目 M1 优先用序列帧 sprite sheet，避免这个坑；
- 音频：短音效 OGG，BGM 用 OGG/MP3 + 音量设置；中文界面字体做子集化（体积）；
- 资源管线：图集打包（TexturePacker/免费替代）、压缩、按场景分包，M1 再引入。

## 6. 发布前许可检查清单

- [ ] 仓库里没有任何官方素材/数据（`git log -S` 抽查 + 文件搜索）
- [ ] `public/assets/` 每个文件都能说清来源与许可，CC-BY 已在 `NOTICE.md` 署名
- [ ] 字体是 OFL 或已确认可商用；Spine Runtimes 许可已随包附带
- [ ] 音频逐条登记来源/作者/许可
- [ ] `NOTICE.md` 写明「非官方、非商业、与鹰角无关」
- [ ] 如果使用官方素材：只在本机构建、不公开分发；发布版换成占位或授权素材
- [ ] 如果收费/广告/赞助：**停下来**，先把所有素材换成可商用授权
